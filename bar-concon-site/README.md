# BAR CONCON 公式サイト

GitHub Pagesでそのまま公開できる静的サイト一式です。

## ファイル
- index.html
- style.css
- script.js
- assets/
- sitemap.xml
- robots.txt

## 公開手順
1. GitHubで新しいPublicリポジトリを作成
2. このフォルダ内のファイルをすべてアップロード
3. Settings → Pages
4. Deploy from a branch
5. main / (root) を選んで保存

## 公開後にやるSEO仕上げ
公開URLが決まったら、index.html の <head> に canonical と og:url を追加し、
sitemap.xml と robots.txt の URL も公開URLに合わせて更新してください。
